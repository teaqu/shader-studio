# Keyboard Shortcuts


## Extension Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+\`` | Toggle the editor overlay (when shader preview is focused) |
| `Ctrl+Enter` | Compile now (works in any mode; required in manual compile mode) |
| `Ctrl+L` / `Cmd+L` | Lock/unlock the current shader |

## Editor Overlay

Use the usual editor shortcuts for selecting text, copying, pasting, and undoing edits. Additional shortcuts:

| Shortcut | Action |
|----------|--------|
| `Ctrl+\`` | Close the editor overlay |

### Vim Mode

When Vim mode is enabled, standard Vim keybindings are active, including `/` search in the overlay.

## Performance

| Shortcut | Action |
|----------|--------|
| Scroll | Pan through history |
| `Ctrl+Scroll` | Zoom Y-axis |
| Drag | Pan horizontally and vertically |
| Click | Pause/resume graph |
